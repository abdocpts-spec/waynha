# هوية وينها | WAYNHA — ملفات الشعار

الفكرة: «من السؤال إلى المكان». علامة سؤال «؟» يخرج منها مسار منقّط ينتهي عند دبوس الموقع.

## الألوان

| الاسم | القيمة | الاستخدام |
|---|---|---|
| أزرق وينها | `#1A56DB` | الدبوس، خلفية أيقونة التطبيق |
| فيروزي | `#0E9F87` | المسار ونقطة السؤال |
| كحلي | `#0B1F4D` | كلمة «وينها» والخلفيات الداكنة |
| أزرق فاتح (للداكن) | `#5B8DEF` | الدبوس على الخلفية الداكنة |
| فيروزي فاتح (للداكن) | `#2DD4BF` | المسار على الخلفية الداكنة |

الخط: Cairo (ExtraBold للعربية، Bold للإنجليزية). النصوص في ملفات SVG محوّلة إلى أشكال مرسومة، فلا تحتاج الخط مثبّتًا.

## الملفات

`svg/` (متجهية، للطباعة والتعديل):

- `waynha-logo-horizontal-*`: الشعار الرئيسي الأفقي (الرمز + وينها + WAYNHA).
- `waynha-logo-arabic-*`: الرمز + وينها.
- `waynha-logo-english-*`: الرمز + WAYNHA.
- `waynha-logo-stacked-*`: النسخة المربعة/المكدّسة.
- `waynha-icon-*`: الرمز وحده.
- `waynha-app-icon.svg` و `-flat` و `-maskable`: أيقونة التطبيق.
- `waynha-favicon.svg`: أيقونة المتصفح المبسّطة (بدون المسار المنقّط).

اللاحقة تحدد النسخة: `color` للخلفية البيضاء، `dark` للخلفية الداكنة، `black` أحادي أسود، `white` أحادي أبيض.

`png/`: نسخ PNG بخلفية شفافة (الشعارات بدقة @2x، وأيقونات التطبيق 1024/512/192/180، و favicon 16/32/48 و `favicon.ico`).

`legacy/`: الأيقونات القديمة قبل الاستبدال.
